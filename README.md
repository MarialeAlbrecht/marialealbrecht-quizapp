# 📱 Quiz App – My First Coding Project

This project was created during my **Web Development Bootcamp at Neuefische** and represents my **first step into the coding world** 🌱.

I built a **mobile quiz app** with questions about **HTML and CSS** — a way to learn while also practicing the fundamentals of web development.

---

## 🛠️ Tech Stack

* **HTML**
* **CSS**
* **JavaScript**

---

## 🎯 Features

* ✅ Quiz questions about HTML & CSS
* 🔖 Bookmark feature to save questions for later
* 👀 Hide/Show functionality for answers
* 📝 A form to add new questions directly into the quiz
* 📱 Mobile-friendly design

---

## 💡 Challenges

The most exciting challenges I faced:

* Implementing the **bookmark function** so users can save specific questions
* Making the **hide/show buttons** work properly for toggling answers
